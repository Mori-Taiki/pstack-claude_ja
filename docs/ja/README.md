## 読み方

最初に日本語 README で全体像をつかみ、次に Poteto mode を読むと、このスキル集がどう仕事を進めるかが分かります。特定の機能を探す場合はスキル一覧から原文へ移動できます。

`poteto-mode` はタスクを分類し、プレイブックという作業手順を選びます。`how` や `why` は調査、`architect` は設計、`arena` や `swarm` は並行作業、`interrogate` や `thermos` はレビューを担当します。`principle-*` は、各場面の判断基準を定義する参照用スキルです。

「スキル一覧」は用途の翻訳であり、各スキル本文の全文訳ではありません。上の一覧にない文書、コードのコメント、画像内の英語は未翻訳です。リンク先が英語の原文である場合があります。

## 翻訳の基準

翻訳元は `michael-denyer/pstack-claude` のコミット `7bad1ebc26faa268806bfbb84e5af55d178b68e4` です。コマンド、API 名、設定キー、モデル名、ファイルパスは原文に合わせています。原文の制約、例外、未検証の範囲を保ち、要約と全文訳を区別しています。

原文のスキル本文にはエージェントへの命令が含まれます。日本語版はそれを読んで理解するための翻訳です。日本語版を追加しただけでは、エージェントの実行時の振る舞いや表示言語は変わりません。
